# interactive-tic-tac-toe-146098-146174

This workspace contains a Remotion-based frontend for an interactive Tic Tac Toe game.

- Container: tic_tac_toe_frontend
- Composition: TicTacToe

Quick start:
1. cd tic_tac_toe_frontend
2. npm i
3. npm run dev
4. In Remotion Studio, open the TicTacToe composition.

Theme: Ocean Professional (primary #2563EB, secondary #F59E0B, text #111827).
